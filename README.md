# SNR-Aware Automatic Modulation Classification

Machine learning project for automatic modulation classification from complex I/Q signals under different SNR conditions.

## Objectives

- Explore and preprocess the RadioML 2016.10A dataset.
- Extract time-domain and frequency-domain signal features.
- Compare classical machine learning classifiers.
- Evaluate performance across different SNR levels.
- Build a reproducible and documented RF machine learning pipeline.
